## 🏥 SavMed Clinic

A modern responsive website developed for **SavMed**, a medical clinic specializing in musculoskeletal health and treatment.

The project focuses on presenting the clinic's services, treatment methods, medical specialists, certificates, medical products, and contact information in a clear and user-friendly interface.

### Key features

- 📱 Fully responsive design for desktop, tablet, and mobile devices.
- 🌍 Multilingual interface.
- 🩺 Detailed presentation of clinic services and treatment methods.
- 👨‍⚕️ Doctors and clinic information sections.
- 📜 Interactive certificates section.
- 🦴 Medical products catalog.
- 🗺️ Clinic location and contact information.
- ✨ Interactive UI elements, animations, sliders, and responsive navigation.
- 🚀 Deployed as a production website.

### Tech Stack

**Frontend:** React, TypeScript, Vite  
**Styling:** CSS  
**Deployment:** Vercel
